## How to Run

### Prerequisites
- Node.js or any modern JavaScript runtime (browser console)
- Text editor or IDE

### Execution

**In Node.js:**
```bash
node phase-1/prog-01.js
```

**In Browser Console:**
1. Copy the code from any `.js` file
2. Paste into browser developer console (F12)
3. Press Enter to execute
